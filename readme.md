# gamebook repo - a multilingual text adventure

this is a multilingual text adventure that supports currently English, Russian and Toki Pona.
support for languages other than English are only partial - unfortunately. 

for the legal stuff and sources etc. please look at source.md 

# how to play 

Just clone the repo, go to the **ilomusi** directory and start the whole thing with 
   npm start
   
This has currently only a cli or command line version.

## requirements
You might need Node.js or NVM with the version 23 or higher. 

## supported scripts

This game supports a lot scripts for Toki Pona like 

   - UCSUR (make sure you have it installed and running)
   - Akesi (that's basically ASCII substitutes for the Sitelen Pona)
   - Junikoto (unicode substitutes for the Sitelen Pona)
   - Sijeka (asian alternatives to Sitelen Pona)
      take a look at https://telegra.ph/Sitelen-Ma-Pi-Suno-Kama-08-11
